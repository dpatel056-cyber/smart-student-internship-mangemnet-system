# Smart Student Internship Management System (SIMS)

A comprehensive web-based platform built with **ASP.NET (C#)** and **Microsoft SQL Server** designed to streamline student internships, company recruitment, and institutional tracking.

## 🚀 Features

- **Public Portal:** Browse internships, explore verified companies, read student success stories, and access FAQs.
- **Student Panel:** Profile management, resume upload/preview, explore internships, apply with filters & pagination, track application status, interview schedules, tasks, and offer letters.
- **Company Panel:** Post & manage internship opportunities, review applicants, shortlist candidates, schedule interviews, issue offer letters & certificates, and analyze hiring reports.
- **Admin Panel:** Complete overview dashboard, company verification, student monitoring, internship approval, feedback & ratings moderation, detailed analytics charts, and report generation.

## 🛠️ Technology Stack

- **Backend:** ASP.NET Web Forms, C#, 2-Tier Architecture (ADO.NET)
- **Database:** Microsoft SQL Server (LocalDB / Express)
- **Frontend:** HTML5, CSS3, JavaScript, FontAwesome, Chart.js
- **Reporting:** iTextSharp, BouncyCastle for PDF generation
